## 1. 显示模式 `display`

常见显示模式：

| 值 | 特点 |
| --- | --- |
| `block` | 块级元素，独占一行，可设置宽高 |
| `inline` | 行内元素，不独占一行，宽高通常无效 |
| `inline-block` | 行内块，可同行显示，也可设置宽高 |
| `none` | 元素不显示，也不占位置 |
| `flex` | 开启弹性布局 |
| `grid` | 开启网格布局 |

`display` 是布局的入口，很多布局问题都可以先从元素当前显示模式开始排查。

## 2. 浮动布局 `float`

浮动最初用于图文环绕，后来曾经常用于页面布局。

```css
.item {
  float: left;
}
```

浮动特点：

- 元素会脱离标准文档流。
- 多个浮动元素会尽量在一行排列。
- 父元素如果只包含浮动子元素，可能发生高度塌陷。

### 清除浮动

常见伪元素清除浮动：

```css
.clearfix::after {
  content: "";
  display: block;
  clear: both;
}
```

工程中现在更推荐 Flex/Grid 做整体布局，但理解浮动有助于阅读旧代码。

## 3. Flex 弹性布局

Flex 适合一维布局：一行或一列中的元素排列。

```css
.container {
  display: flex;
}
```

### 父容器常用属性

| 属性 | 作用 |
| --- | --- |
| `flex-direction` | 主轴方向 |
| `justify-content` | 主轴对齐 |
| `align-items` | 交叉轴单行对齐 |
| `align-content` | 多行交叉轴对齐 |
| `flex-wrap` | 是否换行 |
| `gap` | 项目间距 |

### 子项目常用属性

| 属性 | 作用 |
| --- | --- |
| `flex` | 放大、缩小、基础尺寸简写 |
| `flex-grow` | 是否放大 |
| `flex-shrink` | 是否缩小 |
| `flex-basis` | 主轴基础尺寸 |
| `align-self` | 单个子项交叉轴对齐 |

`flex: 1` 常表示子项平分剩余空间。

## 4. 定位布局 `position`

| 值 | 是否脱离文档流 | 定位参照 |
| --- | --- | --- |
| `static` | 否 | 默认值 |
| `relative` | 否 | 自身原位置 |
| `absolute` | 是 | 最近的定位祖先 |
| `fixed` | 是 | 浏览器窗口 |
| `sticky` | 视情况 | 滚动容器 |

### 子绝父相

```css
.parent {
  position: relative;
}

.child {
  position: absolute;
  right: 0;
  top: 0;
}
```

`absolute` 会寻找最近的“非 static 定位祖先”。如果找不到，就可能相对浏览器窗口或初始包含块定位。

## 5. 层叠顺序 `z-index`

`z-index` 控制定位元素的前后层级。

```css
.modal {
  position: fixed;
  z-index: 1000;
}
```

注意：

- `z-index` 通常对定位元素更有效。
- 层级不是越大越好，项目里应该有层级规范。
- 父元素可能创建层叠上下文，导致子元素再大也盖不过外部元素。

## 6. Grid 网格布局

Grid 适合二维布局：既控制行，也控制列。

```css
.list {
  display: grid;
  grid-template-columns: repeat(4, 1fr);
  gap: 20px;
}
```

常用属性：

| 属性 | 作用 |
| --- | --- |
| `grid-template-columns` | 定义列 |
| `grid-template-rows` | 定义行 |
| `gap` | 网格间距 |
| `repeat()` | 重复轨道 |
| `fr` | 剩余空间比例单位 |
| `minmax()` | 最小最大尺寸 |
| `auto-fill` | 自动填充列 |

响应式卡片列表常用：

```css
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(210px, 1fr));
  gap: 20px;
}
```

## 7. 多列布局和鼠标样式

### 多列布局

```css
.article {
  column-count: 3;
  column-gap: 30px;
}
```

适合长文本排版，不适合复杂卡片布局。

### 鼠标样式

```css
.button {
  cursor: pointer;
}
```

常见值：`default`、`pointer`、`text`、`move`、`not-allowed`。

## 布局选择建议

| 场景 | 推荐 |
| --- | --- |
| 导航栏、按钮组、单行对齐 | Flex |
| 卡片网格、图片墙、二维区域 | Grid |
| 元素叠放、角标、弹窗 | Position |
| 图文环绕、旧代码兼容 | Float |
| 多列文章文本 | Multi-column |

## 易错点

- 浮动会导致父元素高度塌陷。
- `align-items` 是交叉轴对齐，`justify-content` 是主轴对齐。
- `flex-direction` 改变后，主轴和交叉轴也会改变。
- `absolute` 的参照物不是一定是父元素，而是最近的定位祖先。
- `fixed` 会相对视口固定，常用于返回顶部、固定导航、遮罩层。
- Grid 的 `fr` 分配的是剩余空间，不是固定像素。

## 工程实践补充

- 新项目布局优先考虑 Flex 和 Grid。
- 不要为了居中滥用定位，Flex 居中通常更简单。
- 复杂页面可以外层 Grid 控整体区域，内部 Flex 控局部排列。
- 固定定位元素要考虑移动端遮挡、层级和滚动体验。
- 响应式布局中，`minmax()`、`auto-fill`、`gap` 比写死宽度更灵活。
