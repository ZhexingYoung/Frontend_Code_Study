# 1. 样式选择器：课堂笔记

> 本章目标：掌握 CSS 的引入方式、选择器、文字样式、伪类伪元素和权重规则，能判断样式为什么生效或不生效。

## 1. CSS 的作用

HTML 负责结构，CSS 负责样式。

CSS 可以控制：

- 文字颜色、大小、粗细、字体。
- 盒子的宽高、边距、边框、背景。
- 页面布局。
- 鼠标悬停、焦点、选中等状态。
- 动画和交互视觉效果。

## 2. CSS 引入方式

### 行内样式

```html
<p style="color: red;">文字</p>
```

优点是直接，缺点是难维护、难复用。适合临时测试。

### 内部样式表

```html
<style>
  p {
    color: red;
  }
</style>
```

适合单文件练习。

### 外部样式表

```html
<link rel="stylesheet" href="./css/my.css">
```

真实项目推荐外部样式表，结构和样式分离，方便复用和维护。

## 3. 基础选择器

| 选择器 | 示例 | 说明 |
| --- | --- | --- |
| 类型选择器 | `p {}` | 选中所有 `p` 标签 |
| 类选择器 | `.box {}` | 选中 `class="box"` 的元素 |
| ID 选择器 | `#app {}` | 选中 `id="app"` 的元素 |
| 通配符选择器 | `* {}` | 选中所有元素 |

类选择器是工程中最常用的选择器，因为它可复用、权重适中、便于命名。

类名建议：

- 使用英文。
- 多个单词用短横线连接：`.product-card`。
- 语义清楚，不要只写 `.red`、`.big` 这种纯样式类，除非是工具类。

## 4. 关系选择器

| 选择器 | 示例 | 含义 |
| --- | --- | --- |
| 后代选择器 | `.box p` | `.box` 里面所有 `p` |
| 子代选择器 | `.box > p` | `.box` 的直接子元素 `p` |
| 相邻兄弟选择器 | `h2 + p` | 紧挨在 `h2` 后面的第一个 `p` |
| 通用兄弟选择器 | `h2 ~ p` | `h2` 后面的所有兄弟 `p` |
| 并集选择器 | `h1, h2, p` | 多个选择器共用样式 |
| 交集选择器 | `p.active` | 同时满足 `p` 标签和 `active` 类 |

工程中不要把选择器写得过长，例如 `.page .main .left .list li a span`，这种样式后期很难覆盖。

## 5. 文字和文本样式

### 字体相关

| 属性 | 说明 |
| --- | --- |
| `color` | 字体颜色 |
| `font-size` | 字体大小 |
| `font-family` | 字体族 |
| `font-weight` | 字体粗细 |
| `font-style` | 字体样式 |
| `text-decoration` | 文本装饰线 |

### 文本布局

| 属性 | 说明 |
| --- | --- |
| `text-align` | 文本水平对齐 |
| `text-indent` | 首行缩进 |
| `letter-spacing` | 字间距 |
| `line-height` | 行高 |

单行文字垂直居中常见写法：

```css
.btn {
  height: 40px;
  line-height: 40px;
}
```

### `font` 简写

```css
p {
  font: italic 700 16px/1.5 Arial, sans-serif;
}
```

注意：`font-size` 和 `font-family` 是简写中必须保留的核心部分。

## 6. 继承性和层叠性

### 继承性

子元素会继承父元素的一部分文本样式，例如：

- `color`
- `font-size`
- `font-family`
- `line-height`

宽高、边框、内外边距通常不会继承。

### 层叠性

多个样式作用到同一个元素时，浏览器会根据来源、权重和书写顺序决定最终样式。

## 7. 伪类选择器

### 链接伪类

```css
a:link {}
a:visited {}
a:hover {}
a:active {}
```

常见顺序：`link`、`visited`、`hover`、`active`。

### 用户行为伪类

```css
input:focus {
  border-color: orange;
}
```

用于焦点状态，表单交互中非常常见。

### 结构伪类

```css
li:nth-child(odd) {}
li:nth-child(even) {}
li:first-child {}
li:last-child {}
```

适合隔行变色、首尾元素特殊处理。

### 表单伪类

```css
input:checked + label {}
button:disabled {}
```

可以根据选中、禁用等状态改变样式。

## 8. 属性选择器和伪元素

### 属性选择器

```css
input[type="text"] {}
a[target="_blank"] {}
```

适合根据标签属性精确选择元素。

### 伪元素

```css
p::first-letter {}
p::first-line {}
.box::before {}
.box::after {}
```

`::before` 和 `::after` 常用于装饰图形、清除浮动、添加小图标。

## 9. 权重规则

从高到低理解：

1. 行内样式。
2. ID 选择器。
3. 类选择器、伪类、属性选择器。
4. 标签选择器、伪元素。
5. 通配符和继承样式。

同权重时，后写的样式覆盖先写的样式。

不建议一遇到覆盖问题就使用 `!important`。它会提高维护成本，真实项目中应谨慎使用。

## 易错点

- 类选择器前面要加 `.`，ID 选择器前面要加 `#`。
- `class` 可以重复使用，`id` 页面中应该唯一。
- `:hover` 是伪类，`::before` 是伪元素。
- 伪元素常常需要写 `content` 才能显示。
- 继承样式权重很低，容易被直接选中元素的样式覆盖。
- 选择器越长不代表越好，过长会导致后期维护困难。

## 工程实践补充

- 项目中优先使用类选择器，不要过度依赖标签选择器和 ID 选择器。
- 公共基础样式可以单独放在 `base.css`，页面样式放在对应页面 CSS 中。
- 类名要描述模块和内容，例如 `.news-card` 比 `.box1` 更容易维护。
- 真实项目中会遇到组件样式隔离、命名冲突、第三方样式覆盖等问题，权重意识非常重要。
