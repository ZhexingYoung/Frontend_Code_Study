## 1. 变换 `transform`

`transform` 改变元素的视觉位置、角度和大小，通常不影响文档流。

常用函数：

| 函数 | 作用 |
| --- | --- |
| `translate(x, y)` | 位移 |
| `rotate(deg)` | 旋转 |
| `scale(x, y)` | 缩放 |
| `skew(x, y)` | 斜切 |

示例：

```css
.box:hover {
  transform: translateY(-8px) scale(1.03);
}
```

多个变换可以连写，执行顺序会影响最终效果。

## 2. 变换原点

```css
.box {
  transform-origin: center center;
}
```

`transform-origin` 决定旋转、缩放等变换围绕哪个点发生。常见值：

- `center`
- `left top`
- `right bottom`
- `50% 50%`

## 3. 过渡 `transition`

过渡用于让属性变化更平滑。

```css
.card {
  transition: transform .3s ease, box-shadow .3s ease;
}

.card:hover {
  transform: translateY(-6px);
  box-shadow: 0 12px 30px rgba(0, 0, 0, .16);
}
```

常用组成：

| 部分 | 示例 |
| --- | --- |
| 过渡属性 | `transform` |
| 持续时间 | `.3s` |
| 速度曲线 | `ease`、`linear` |
| 延迟时间 | `.1s` |

过渡适合“从一个状态变到另一个状态”，例如 hover、focus、active。

## 4. 关键帧动画 `animation`

动画适合持续播放或多阶段变化。

```css
@keyframes move {
  0% {
    transform: translateX(0);
  }
  100% {
    transform: translateX(100px);
  }
}

.box {
  animation: move 1s linear infinite;
}
```

常用属性：

| 属性 | 说明 |
| --- | --- |
| `animation-name` | 动画名称 |
| `animation-duration` | 持续时间 |
| `animation-timing-function` | 速度曲线 |
| `animation-delay` | 延迟 |
| `animation-iteration-count` | 播放次数 |
| `animation-direction` | 播放方向 |
| `animation-fill-mode` | 播放前后状态 |
| `animation-play-state` | 播放或暂停 |

## 5. 逐帧动画 `steps()`

`steps()` 适合雪碧图帧动画。

```css
.sprite {
  animation: run 1s steps(25) infinite;
}
```

含义：把动画过程切成指定份数，一格一格跳变，不做平滑补间。

## 6. 3D 变换

常用属性：

| 属性 | 作用 |
| --- | --- |
| `perspective` | 设置透视距离 |
| `transform-style: preserve-3d` | 保留子元素 3D 空间 |
| `rotateX()` | 绕 X 轴旋转 |
| `rotateY()` | 绕 Y 轴旋转 |
| `translateZ()` | Z 轴位移 |
| `backface-visibility` | 控制背面是否可见 |

翻转卡片常见结构：

```css
.card {
  perspective: 1000px;
}

.inner {
  transform-style: preserve-3d;
  transition: transform .6s;
}

.card:hover .inner {
  transform: rotateY(180deg);
}
```

## 7. 常见动效案例思路

### 彩色按钮边框

常用思路：

- 背景渐变模拟彩色边框。
- 内层元素覆盖中间区域。
- hover 时改变背景位置或旋转伪元素。

### 流光按钮

常用思路：

- `::before` 或 `::after` 做光线层。
- 使用 `linear-gradient`。
- 通过 `transform` 或 `background-position` 移动光线。

### 卡片悬停

常用思路：

- `transform: translateY()` 让卡片上浮。
- `box-shadow` 增强层次。
- `transition` 控制平滑程度。

### 滚动盒子

常用思路：

- 内容复制一份，实现无缝衔接。
- 使用 `translateX()` 或 `translateY()`。
- 鼠标悬停时暂停动画。

## 易错点

- `transform` 不会真正改变元素在文档流中的占位。
- `transition` 要写在原始状态上，不要只写在 `:hover` 上。
- 多个 `transform` 属性不能分开写，否则后面的会覆盖前面的。
- 3D 效果需要透视和 3D 空间配合。
- 动画太多会影响性能和阅读体验。
- `steps()` 是跳帧，不是平滑过渡。

## 工程实践补充

- 优先动画化 `transform` 和 `opacity`，性能通常更好。
- 少动画化 `width`、`height`、`top`、`left`，它们更容易触发布局计算。
- 动效要服务于交互反馈，不要为了炫技影响用户操作。
- 复杂动效要考虑低性能设备和用户的“减少动态效果”偏好。
- 真实项目中可以使用 CSS 变量统一动效时间，例如 `--duration-fast: .2s`。
