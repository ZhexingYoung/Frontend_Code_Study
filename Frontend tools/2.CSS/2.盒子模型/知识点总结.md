## 1. 盒子模型组成

每个 HTML 元素都可以看成一个盒子：

```text
margin
  border
    padding
      content
```

对应 CSS：

```css
.box {
  width: 200px;
  height: 100px;
  padding: 20px;
  border: 1px solid #ccc;
  margin: 20px;
}
```

## 2. 边框和圆角

### 边框

```css
.box {
  border: 1px solid #333;
}
```

完整写法包含：

- `border-width`：边框宽度。
- `border-style`：边框样式，常用 `solid`、`dashed`、`dotted`。
- `border-color`：边框颜色。

### 圆角

```css
.card {
  border-radius: 12px;
}
```

常见技巧：

- 胶囊按钮：`border-radius` 设置为高度的一半或更大。
- 圆形头像：正方形盒子设置 `border-radius: 50%`。
- 四角单独设置：`border-radius: 左上 右上 右下 左下`。

## 3. 内边距和外边距

### 内边距 `padding`

`padding` 是内容和边框之间的距离，会撑大盒子。

```css
.box {
  padding: 10px 20px;
}
```

速记：

- 1 个值：上下左右。
- 2 个值：上下、左右。
- 3 个值：上、左右、下。
- 4 个值：上、右、下、左。

### 外边距 `margin`

`margin` 是盒子和盒子之间的距离。

```css
.box {
  margin: 20px auto;
}
```

`margin: 0 auto` 常用于块级盒子水平居中，但前提是盒子有明确宽度。

## 4. 盒子尺寸计算

默认模型：

```css
box-sizing: content-box;
```

实际占用宽度 = `width + padding + border`。

推荐模型：

```css
box-sizing: border-box;
```

实际占用宽度 = `width`，`padding` 和 `border` 包含在 `width` 里面。

工程中常见初始化：

```css
* {
  box-sizing: border-box;
}
```

这样布局更可控。

## 5. 背景和渐变

### 背景图片

```css
.banner {
  background-image: url("./img/bg.jpg");
  background-repeat: no-repeat;
  background-position: center;
  background-size: cover;
}
```

常用属性：

| 属性 | 作用 |
| --- | --- |
| `background-color` | 背景颜色 |
| `background-image` | 背景图片 |
| `background-repeat` | 是否重复 |
| `background-position` | 背景位置 |
| `background-size` | 背景尺寸 |

### 渐变

```css
.box {
  background: linear-gradient(90deg, #ff7a18, #af002d);
}
```

渐变本质上属于背景图片，可以用在按钮、卡片、遮罩等视觉效果中。

## 6. 盒子阴影

```css
.card {
  box-shadow: 0 8px 24px rgba(0, 0, 0, .12);
}
```

参数理解：

```text
x 偏移 y 偏移 模糊半径 扩散半径 颜色
```

配合过渡可以做悬停效果：

```css
.card {
  transition: box-shadow .3s, transform .3s;
}

.card:hover {
  transform: translateY(-4px);
  box-shadow: 0 12px 32px rgba(0, 0, 0, .18);
}
```

## 7. 字体图标

字体图标把图标当作字体使用，常见于 iconfont。

常见步骤：

1. 引入 `iconfont.css`。
2. 给元素添加基础类名 `iconfont`。
3. 添加具体图标类名或使用字体编码。

```html
<span class="iconfont icon-search"></span>
```

注意权重问题：如果图标类样式被其他 CSS 覆盖，需要检查选择器和加载顺序。

## 8. 精灵图

精灵图也叫雪碧图，把多个小图标合并到一张图里，通过 `background-position` 显示不同区域。

```css
.icon {
  width: 32px;
  height: 32px;
  background-image: url("./img/sprite.png");
  background-position: -90px -170px;
}
```

现在真实项目中更常见的是 SVG、字体图标、图片组件，但精灵图仍有助于理解背景定位。

## 易错点

- 默认 `content-box` 下，`padding` 和 `border` 会让盒子变大。
- 行内元素设置宽高通常不生效。
- `margin: auto` 居中需要块级元素和固定宽度。
- 背景图片路径是相对于 CSS 文件位置，不一定相对于 HTML 文件。
- 圆形图片要求盒子宽高相等，再设置 `border-radius: 50%`。
- `box-shadow` 不占文档空间，不会影响其他元素布局。

## 工程实践补充

- 项目初始化建议统一设置 `box-sizing: border-box`。
- 卡片、按钮、弹窗等组件都离不开盒子模型。
- 背景图适合装饰，内容图更适合用 `img`，因为 `img` 有语义和 `alt`。
- 阴影和渐变要克制使用，避免页面视觉过重。
- 多行文本省略需要兼容性写法，常见于商品卡片和文章列表。
