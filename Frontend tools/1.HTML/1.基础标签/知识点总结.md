## 1. HTML 页面基本结构

HTML 用来描述网页结构。一个标准页面通常包含：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8">
  <title>页面标题</title>
</head>
<body>
  页面内容
</body>
</html>
```

- `<!DOCTYPE html>`：告诉浏览器使用 HTML5 标准解析。
- `html`：根标签。
- `head`：放页面配置、标题、编码等信息。
- `body`：放用户能看到的内容。
- `meta charset="UTF-8"`：处理中文页面时很重要。

## 2. 标题、段落和文本标签

### 标题标签

`h1` 到 `h6` 表示 6 级标题，数字越小级别越高。

- `h1`：页面主标题，通常一个页面只用一次。
- `h2`：模块标题。
- `h3` 到 `h6`：更细层级的小标题。

### 段落和换行

- `p`：表示一段完整文字，自带段落间距。
- `br`：强制换行，只改变显示，不表示新的段落。

实际写文章或说明内容时，优先用 `p`；只有诗歌、地址、短行文本等需要强制换行时再用 `br`。

### 常见文本语义

| 标签 | 显示效果 | 语义 |
| --- | --- | --- |
| `strong` | 加粗 | 强调重要内容 |
| `em` | 倾斜 | 语气强调 |
| `del` | 删除线 | 删除、原价 |
| `ins` | 下划线 | 插入、新增 |

工程里尽量使用有语义的标签，而不是只为了样式滥用标签。样式可以交给 CSS。

## 3. 块级元素和行内元素

### 块级元素

常见：`div`、`p`、`h1`-`h6`、`ul`、`ol`、`li`。

特点：

- 独占一行。
- 默认宽度通常占满父元素。
- 可以设置宽高、内外边距。

### 行内元素

常见：`span`、`a`、`strong`、`em`。

特点：

- 不独占一行。
- 宽高通常由内容撑开。
- 设置宽高不一定生效。

### 行内块元素

常见：`img`、`input`。

特点：

- 可以和其他元素在一行显示。
- 可以设置宽高。

后续学 CSS 布局时，`display` 会改变元素显示模式，这是理解布局的基础。

## 4. 图片标签和路径

图片使用 `img` 标签：

```html
<img src="./猪爸爸.png" alt="猪爸爸图片" width="300">
```

常用属性：

| 属性 | 作用 |
| --- | --- |
| `src` | 图片地址 |
| `alt` | 图片无法显示时的替代文本 |
| `title` | 鼠标悬停提示 |
| `width` / `height` | 图片显示宽高 |

### 路径速查

- `./`：当前目录。
- `../`：上一级目录。
- `assets/image/a.jpg`：进入子目录。
- `https://...`：网络绝对路径。

工程实践：

- 项目内图片优先用相对路径，方便移动项目。
- 不建议同时固定 `width` 和 `height`，容易拉伸图片；常见做法是设置一个方向，另一个自动等比缩放。
- 内容图片写清楚 `alt`，装饰图片可写 `alt=""`。

## 5. 音频和视频

### 音频

```html
<audio src="../Media/ldh.mp3" controls></audio>
```

### 视频

```html
<video src="../Media/yu7.mp4" controls poster="../Media/yu7.jpg"></video>
```

常用属性：

| 属性 | 说明 |
| --- | --- |
| `controls` | 显示播放控件 |
| `autoplay` | 自动播放 |
| `loop` | 循环播放 |
| `muted` | 静音 |
| `poster` | 视频封面图 |

浏览器通常会限制带声音的自动播放。如果需要自动播放视频，实际项目中经常配合 `muted`。

## 6. 超链接和锚点

超链接使用 `a` 标签：

```html
<a href="https://www.deepseek.com/" target="_blank" title="点击跳转 deepseek">外部链接</a>
```

常见链接类型：

| 类型 | 写法 |
| --- | --- |
| 外部链接 | `href="https://example.com"` |
| 内部页面 | `href="./about.html"` |
| 空链接 | `href="#"` |
| 下载链接 | `href="./file.zip"` |
| 邮件链接 | `href="mailto:test@example.com"` |
| 锚点链接 | `href="#section1"` |

锚点跳转要求：

```html
<a href="#news">今日要闻</a>
<h2 id="news">今日要闻</h2>
```

`href` 里的 `#news` 必须能找到页面中 `id="news"` 的元素。

## 易错点

- `id` 尽量使用英文、数字、短横线，不建议使用中文引号或特殊符号。
- `target="_blank"` 会打开新页面；真实项目里外部链接还会考虑安全属性 `rel="noopener noreferrer"`。
- `img` 是单标签，不需要写结束标签。
- `audio`、`video` 需要浏览器支持对应格式；视频常用 `mp4`。
- 页面标题结构要按层级写，不要只为了字体大小乱用 `h1` 到 `h6`。
