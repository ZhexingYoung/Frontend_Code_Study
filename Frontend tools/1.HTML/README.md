## 高频标签速查

### 文档结构

| 标签 | 作用 | 备注 |
| --- | --- | --- |
| `<!DOCTYPE html>` | 声明 HTML5 文档 | 放在第一行 |
| `<html>` | 页面根元素 | 常配合 `lang="zh-CN"` |
| `<head>` | 页面元信息 | 放 `meta`、`title`、样式等 |
| `<body>` | 页面可见内容 | 用户实际看到的内容 |
| `<meta charset="UTF-8">` | 设置字符编码 | 避免中文乱码 |
| `<title>` | 浏览器标签页标题 | 不是页面大标题 |

### 文本与内容

| 标签 | 作用 | 速记 |
| --- | --- | --- |
| `h1`-`h6` | 标题 | `h1` 一般一个页面一个 |
| `p` | 段落 | 段落之间自带间距 |
| `br` | 换行 | 只换行，不产生段落语义 |
| `strong` | 强调加粗 | 有语义 |
| `em` | 强调倾斜 | 有语义 |
| `del` | 删除线 | 常用于原价 |
| `ins` | 下划线插入 | 常用于新增内容 |

### 图片、音视频、链接

| 标签 | 常用属性 | 说明 |
| --- | --- | --- |
| `img` | `src`、`alt`、`width`、`height` | `alt` 是图片无法显示时的说明，也影响可访问性 |
| `a` | `href`、`target`、`title` | `target="_blank"` 新窗口打开 |
| `audio` | `src`、`controls`、`autoplay`、`loop` | 浏览器可能限制自动播放 |
| `video` | `src`、`controls`、`poster`、`muted` | `muted` 常用于允许自动播放 |

### 列表、表格、表单

| 类型 | 标签 | 使用场景 |
| --- | --- | --- |
| 无序列表 | `ul`、`li` | 导航、商品列表、普通项目列表 |
| 有序列表 | `ol`、`li` | 步骤、排名 |
| 自定义列表 | `dl`、`dt`、`dd` | 名词解释、图文说明 |
| 表格 | `table`、`tr`、`th`、`td` | 二维数据展示 |
| 表单 | `form`、`input`、`label`、`textarea`、`select`、`button` | 用户输入和提交 |

## 常见写法

### 锚点跳转

```html
<a href="#section-news">跳转到今日要闻</a>
<h2 id="section-news">今日要闻</h2>
```

### 表单标签关联

```html
<label for="username">用户名</label>
<input id="username" type="text" name="username">
```

### 图片路径选择

```html
<img src="./assets/image/poster.jpg" alt="科技日报封面">
```

## 易错点

- `title` 是浏览器标签页标题，页面中的大标题应该用 `h1`。
- 图片路径建议优先使用相对路径，避免写死本机绝对路径。
- `a` 标签跳转到页面内位置时，`href="#id"` 必须对应目标元素的 `id`。
- 表单里的 `label for` 要和控件 `id` 对应，真实项目里这对可访问性很重要。
- 表格适合展示数据，不建议用表格做页面布局。
- `input` 的 `name` 在提交表单时很关键，只写 `id` 不一定能提交字段。

## 工程实践提醒

- HTML 先负责“结构和语义”，样式交给 CSS，行为交给 JavaScript。
- 真实页面优先使用语义化标签，例如 `header`、`nav`、`main`、`section`、`article`、`footer`。
- 图片必须写清楚 `alt`。装饰图可以写空 `alt=""`，内容图要描述图片含义。
- 链接文本不要只写“点击这里”，应该让用户知道会跳到哪里。
- 表单控件要注意键盘可操作性，后续学习 CSS/JS 时不要把原生交互破坏掉。
