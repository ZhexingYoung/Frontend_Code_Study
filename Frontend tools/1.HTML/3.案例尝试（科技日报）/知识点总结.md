# 3. 案例尝试（科技日报）：课堂笔记

> 本章目标：把 HTML 基础标签组合成一个完整资讯页面，理解页面结构、内容组织、跳转、媒体和表单的综合使用。

## 章节文件索引

- [科技日报.html](./科技日报.html)：完整页面案例。
- `assets/image/`：案例图片资源。
- `assets/video/`：案例视频资源。

## 1. 案例训练重点

这个案例不是学习单个标签，而是练习“如何把多个标签组织成一个页面”。

主要覆盖：

- 页面标题和段落内容。
- 站内锚点导航和站外链接。
- 图片展示。
- 表格数据展示。
- 表单互动。
- 视频内容展示。

## 2. 页面结构拆解

一个资讯类页面通常可以拆成：

```html
<header>页面头部</header>
<nav>导航链接</nav>
<main>
  <section>今日要闻</section>
  <section>行业数据</section>
  <section>读者互动</section>
  <section>科技大讲堂</section>
</main>
<footer>页脚信息</footer>
```

即使练习文件里不一定完全使用这些语义化标签，也可以用这个思路理解页面：

- `header`：放站点名、主标题、简介。
- `nav`：放锚点链接或栏目导航。
- `main`：页面核心内容。
- `section`：每个栏目一块。
- `footer`：版权、补充链接、联系信息。

## 3. 锚点导航

案例中使用了类似“今日要闻、行业数据、读者互动、科技大讲堂”的栏目结构，这类内容很适合用锚点链接。

```html
<a href="#今日要闻">今日要闻</a>
<h2 id="今日要闻">今日要闻</h2>
```

工程建议：

- 学习阶段中文 `id` 可以帮助理解。
- 实际项目更推荐英文或短横线命名，例如 `id="today-news"`。
- 链接文本要写清楚目标，不建议只写“点击这里”。

## 4. 图文内容组织

资讯页常见内容结构：

```html
<article>
  <h2>新闻标题</h2>
  <p>新闻摘要或正文。</p>
  <img src="./assets/image/量子计算机.webp" alt="量子计算机">
</article>
```

注意：

- 图片路径应该相对当前 HTML 文件。
- `alt` 要描述图片内容，不只是写“图片”。
- 多篇文章可以使用多个 `article` 或多个 `section`。

## 5. 数据展示：表格

“行业数据”这类内容适合表格。

```html
<table>
  <thead>
    <tr>
      <th>领域</th>
      <th>数据</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>人工智能</td>
      <td>增长明显</td>
    </tr>
  </tbody>
</table>
```

表格适合表达二维数据。不要为了让页面对齐而使用表格布局，后续应使用 CSS 的 Flex 或 Grid。

## 6. 读者互动：表单

“读者互动”通常会涉及表单：

- 文本输入：姓名、邮箱、留言标题。
- 单选/复选：兴趣方向、订阅选项。
- 文本域：留言内容。
- 按钮：提交、重置。

表单控件建议搭配 `label`：

```html
<label for="message">留言</label>
<textarea id="message" name="message"></textarea>
```

实际工程中，表单需要考虑：

- 必填校验。
- 输入长度限制。
- 提交后的错误提示。
- 防止重复提交。
- 后端再次校验。

## 7. 视频内容

“科技大讲堂”适合使用 `video`：

```html
<video src="./assets/video/科技大讲堂.mp4" controls poster="./assets/image/poster.jpg"></video>
```

常见注意点：

- `controls` 让用户可以播放、暂停、调节进度。
- `poster` 设置封面图。
- 视频文件通常较大，实际项目会考虑压缩、CDN、懒加载。

## 易错点

- 页面内容多时，标题层级要清楚，不要多个栏目都乱用 `h1`。
- 锚点跳转失败时，优先检查 `href="#xxx"` 和 `id="xxx"` 是否完全一致。
- 图片和视频路径要以当前 HTML 文件所在目录为参照。
- 表单控件没有 `name` 时，提交数据可能不完整。
- 资讯页里表格用于数据展示，不用于整体排版。

## 工程实践补充

- 案例页可以继续优化成“语义化页面”：用 `header`、`nav`、`main`、`section`、`article`、`footer` 重构结构。
- 内容型页面要注意可访问性：图片 `alt`、表单 `label`、链接文本都很重要。
- 后续学习 CSS 时，可以给每个模块加清晰类名，例如 `.news-section`、`.data-table`、`.feedback-form`。
- 真实项目中，资源文件建议统一放在 `assets/images`、`assets/videos` 等目录中，并保持命名规范。

- 能在页面中组合图片、表格、表单和视频。
- 能判断哪些内容适合使用 `article`、`section`、`table`、`form`。
- 能说出这个案例后续用 CSS 可以优化哪些地方。
