## 1. 语义化结构标签

语义化标签让页面结构更清楚，也方便搜索引擎、屏幕阅读器和团队协作。

| 标签 | 语义 |
| --- | --- |
| `header` | 页头或模块头部 |
| `nav` | 导航区域 |
| `main` | 页面主要内容 |
| `section` | 页面中的一块内容区域 |
| `article` | 独立文章或内容 |
| `aside` | 侧边栏、补充信息 |
| `footer` | 页脚或模块底部 |

速记：先用语义化标签划分页面大区域，再用 `div` 做没有明确语义的包裹。

## 2. 列表标签

### 无序列表

```html
<ul>
  <li>首页</li>
  <li>新闻</li>
  <li>联系</li>
</ul>
```

适合：导航、商品卡片列表、普通项目列表。

### 有序列表

```html
<ol>
  <li>打开编辑器</li>
  <li>创建 HTML 文件</li>
  <li>运行页面</li>
</ol>
```

适合：步骤、排名、流程。

### 自定义列表

```html
<dl>
  <dt>HTML</dt>
  <dd>负责网页结构</dd>
</dl>
```

适合：名词解释、图文说明、页脚链接组。

工程中导航菜单经常使用 `ul > li > a`，列表结构清晰，后续 CSS 也容易布局。

## 3. 表格标签

表格用于展示二维数据，不建议用来做页面布局。

```html
<table>
  <thead>
    <tr>
      <th>姓名</th>
      <th>成绩</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>小明</td>
      <td>95</td>
    </tr>
  </tbody>
</table>
```

常用标签：

| 标签 | 作用 |
| --- | --- |
| `table` | 表格 |
| `tr` | 表格行 |
| `th` | 表头单元格，默认加粗居中 |
| `td` | 普通单元格 |
| `thead` | 表头区域 |
| `tbody` | 表体区域 |
| `tfoot` | 表尾区域 |

常见属性：

- `rowspan`：跨行合并。
- `colspan`：跨列合并。

## 4. 表单容器

`form` 用来收集用户输入。

```html
<form action="/login" method="post">
  <input type="text" name="username">
  <button type="submit">提交</button>
</form>
```

常见属性：

| 属性 | 说明 |
| --- | --- |
| `action` | 表单提交地址 |
| `method` | 提交方式，常见 `get`、`post` |
| `name` | 控件提交时的字段名 |
| `value` | 提交给服务器的值 |

学习阶段可以先关注结构，后续配合 JavaScript 或后端时，`name` 和 `value` 会变得非常关键。

## 5. 常见表单控件

### 输入框

```html
<input type="text" placeholder="请输入用户名">
<input type="password" placeholder="请输入密码">
```

### 单选框

```html
<input type="radio" name="gender" value="male"> 男
<input type="radio" name="gender" value="female"> 女
```

同一组单选框必须使用相同的 `name`，否则无法互斥。

### 复选框

```html
<input type="checkbox" name="hobby" value="music"> 音乐
<input type="checkbox" name="hobby" value="game"> 游戏
```

### 文件域

```html
<input type="file" name="avatar">
```

### 文本域

```html
<textarea name="message" rows="5" cols="30"></textarea>
```

### 下拉框

```html
<select name="city">
  <option value="beijing">北京</option>
  <option value="shanghai">上海</option>
</select>
```

### 按钮

```html
<button type="submit">提交</button>
<button type="reset">重置</button>
<button type="button">普通按钮</button>
```

在 `form` 内部，`button` 默认可能具有提交行为，实际项目里普通按钮建议明确写 `type="button"`。

## 6. `label` 辅助标签

`label` 可以扩大可点击范围，也能提升可访问性。

```html
<label for="agree">我同意协议</label>
<input id="agree" type="checkbox" name="agree">
```

要求：`label` 的 `for` 必须对应控件的 `id`。

## 7. 字符实体

HTML 中有些字符会被当成语法，需要使用字符实体。

| 字符 | 实体 |
| --- | --- |
| 空格 | `&nbsp;` |
| 小于号 | `&lt;` |
| 大于号 | `&gt;` |
| 与号 | `&amp;` |
| 版权 | `&copy;` |

## 易错点

- `ul`、`ol` 的直接子元素应该是 `li`。
- `table` 适合数据，不适合整体排版。
- 表单控件要写 `name`，否则提交时可能没有字段名。
- 单选框同组必须使用相同 `name`。
- `label for` 对应的是 `id`，不是 `name`。
- `button` 在表单里最好明确写 `type`。

## 工程实践补充

- 页面结构优先语义化，CSS 布局时再加必要的类名。
- 表单交互要考虑键盘操作和屏幕阅读器，不能只追求视觉效果。
- 表格数据较多时，后续需要考虑响应式、固定表头、横向滚动等问题。
- 表单提交前通常需要前端校验，但不能只依赖前端校验，后端也必须校验。
