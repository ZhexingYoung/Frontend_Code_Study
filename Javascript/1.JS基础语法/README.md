# JavaScript 基础语法综合总结

这部分是 JavaScript 入门阶段的第一轮基础知识，重点不是背语法，而是建立“数据如何进入程序、如何被处理、如何输出结果”的完整思路。

整体学习主线：

```text
输入输出
  -> 变量/常量保存数据
  -> 数据类型和类型转换
  -> 运算符处理数据
  -> 分支语句决定走哪条路
  -> 循环语句重复做事情
  -> 数组批量管理数据
  -> 函数封装重复逻辑
  -> 对象描述复杂数据
```

## 章节地图

### 1.1 基础语法数据

主要解决“JavaScript 怎么写、数据怎么存、怎么输入输出”的问题。

核心内容：

- JS 的三种书写位置：内部 JS、外部 JS、行内 JS。
- 输出：`document.write()`、`alert()`、`console.log()`。
- 输入：`prompt()`。
- 变量：`let`，用于保存可变化的数据。
- 常量：`const`，用于保存不希望被重新赋值的数据。
- 数据类型：`number`、`string`、`boolean`、`undefined`、`null`、`object`。
- 字符串拼接和模板字符串。
- 显式类型转换和隐式类型转换。

关键提醒：

```js
let num1 = +prompt('请输入第一个数')
let num2 = +prompt('请输入第二个数')
console.log(num1 + num2)
```

`prompt()` 得到的是字符串，做数学计算前要转成数字。

### 1.2 运算

主要解决“数据之间如何计算和比较”的问题。

核心内容：

- 赋值运算符：`=`、`+=`、`-=`、`*=`、`/=`、`%=`
- 一元运算符：`++`、`--`
- 比较运算符：`>`、`<`、`>=`、`<=`
- 相等判断：`==`、`===`、`!=`、`!==`
- 逻辑运算符：`&&`、`||`、`!`
- 运算符优先级

推荐习惯：

```js
console.log(10 === '10') // false
```

日常判断优先使用 `===`，避免隐式转换造成误判。

### 1.3 语句

主要解决“程序根据不同条件执行不同代码”和“重复执行代码”的问题。

核心内容：

- `if` 单分支。
- `if...else` 双分支。
- `if...else if...else` 多分支。
- 三元运算符。
- `switch` 固定值判断。
- `while` 循环。
- `for` 循环。
- `continue` 和 `break`。
- 循环嵌套。

选择建议：

- 条件结果少，用 `if...else`。
- 固定值匹配多，用 `switch`。
- 循环次数明确，用 `for`。
- 循环次数不明确，用 `while`。

### 1.4 数组

主要解决“如何批量保存和处理一组数据”的问题。

核心内容：

- 数组声明：`let arr = []`
- 索引取值：`arr[0]`
- 数组长度：`arr.length`
- 数组遍历。
- 数组求和、平均值、最大值、最小值。
- 增：`push()`、`unshift()`
- 删：`pop()`、`shift()`、`splice()`
- 改：通过索引重新赋值。
- 筛选：遍历数组，符合条件就放入新数组。
- 排序：冒泡排序和 `sort()`。

遍历模板：

```js
for (let i = 0; i < arr.length; i++) {
  console.log(arr[i])
}
```

数组的核心思路是：用循环逐个处理元素。

### 1.5 函数

主要解决“如何把重复代码封装起来”的问题。

核心内容：

- 函数声明和调用。
- 形参、实参、默认参数。
- `return` 返回值。
- 函数封装数组求和、取最大值、取最小值。
- 作用域：全局作用域、局部作用域。
- 匿名函数。
- 立即执行函数。
- 逻辑中断。
- 布尔型转换。

函数模板：

```js
function getSum(arr = []) {
  let sum = 0

  for (let i = 0; i < arr.length; i++) {
    sum += arr[i]
  }

  return sum
}

console.log(getSum([10, 20, 30]))
```

函数的核心思路是：把变化的数据作为参数，把处理结果用 `return` 返回。

### 1.6 对象

主要解决“如何描述一个复杂事物”的问题。

核心内容：

- 对象是无序键值对集合。
- 属性查询：点语法和中括号语法。
- 属性新增、修改、删除。
- 对象方法。
- `for...in` 遍历对象。
- 数组对象结合渲染列表数据。
- 内置对象 `Math`。
- 随机数公式。
- 基本数据类型和引用数据类型。

对象模板：

```js
let student = {
  name: '小明',
  age: 18,
  gender: '男',
  sayHi: function () {
    console.log('你好')
  }
}

console.log(student.name)
student.sayHi()
```

对象适合描述“一个人、一个商品、一名学生、一条英雄数据”等复杂信息。

## 核心语法速查

### 输入输出

```js
let value = prompt('请输入内容')
alert(value)
console.log(value)
document.write(value)
```

### 类型转换

```js
Number('10')
+'10'
parseInt('12.33px')
parseFloat('12.33px')
String(10)
Boolean(1)
```

### 条件判断

```js
if (条件) {
  // 条件成立
} else {
  // 条件不成立
}
```

### 循环

```js
for (let i = 0; i < 10; i++) {
  console.log(i)
}

let i = 0
while (i < 10) {
  console.log(i)
  i++
}
```

### 数组处理

```js
let arr = [1, 2, 3]

arr.push(4)
arr.pop()

for (let i = 0; i < arr.length; i++) {
  console.log(arr[i])
}
```

### 函数封装

```js
function fn(a = 0, b = 0) {
  return a + b
}

console.log(fn(1, 2))
```

### 对象处理

```js
let obj = {
  name: '张三',
  age: 18
}

console.log(obj.name)
console.log(obj['age'])

for (let key in obj) {
  console.log(key, obj[key])
}
```

### 函数工具案例

常见工具函数：

```js
function some(ele, arr = []) {
  for (let i = 0; i < arr.length; i++) {
    if (arr[i] === ele) {
      return true
    }
  }

  return false
}

function findIndex(ele, arr = []) {
  for (let i = 0; i < arr.length; i++) {
    if (arr[i] === ele) {
      return i
    }
  }

  return -1
}
```

这类案例的核心是：循环数组，找到目标就提前 `return`，找不到就返回默认结果。

### 随机数案例

生成指定范围随机整数：

```js
function getRandom(N, M) {
  return Math.floor(Math.random() * (M - N + 1)) + N
}
```

常见应用：

- 随机点名。
- 猜数字游戏。
- 随机颜色。

## 易错点总览

- `prompt()` 返回字符串，数字计算前要转换。
- 数组索引从 `0` 开始。
- `arr.length` 是数组长度，最后一个元素索引是 `arr.length - 1`。
- 遍历数组时通常写 `i < arr.length`，不是 `i <= arr.length`。
- `==` 会隐式转换，推荐使用 `===`。
- `switch` 的 `case` 后通常要写 `break`。
- `while` 循环必须注意更新变量，避免死循环。
- `return` 会结束函数，并把结果带回函数外。
- 函数内部不写 `let` 直接赋值，容易污染全局变量。
- `obj[key]` 和 `obj.key` 不一样，变量属性名要用中括号。
- `Math.random()` 的范围是 `[0, 1)`，不会取到 `1`。
- 引用类型赋值复制的是引用，不是复制一个新对象。

## 第一部分复习路线

建议按下面顺序复习：

1. 先复习输入输出、变量、数据类型，确认知道数据从哪里来、存在哪里。
2. 再复习运算符，重点掌握 `===`、`&&`、`||`、`%`。
3. 然后复习分支和循环，能写登录判断、闰年判断、累加求和、九九乘法表。
4. 接着复习数组，能完成遍历、求和、筛选、排序。
5. 再复习函数，把数组求和、找最大值、查找元素封装成函数。
6. 最后复习对象，能用数组对象结构渲染学生表格或英雄列表。
