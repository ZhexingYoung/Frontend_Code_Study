# 1.2 运算

## 学习目标

本章主要学习赋值运算符、一元运算符、比较运算符、逻辑运算符和运算符优先级。学习完后，应能完成基础数值计算、条件判断表达式和简单逻辑组合。

## 核心知识点

### 赋值运算符

赋值运算符用于把右侧的值赋给左侧变量。

```javascript
let num = 1

num += 1 // 等价于 num = num + 1
num -= 1
num *= 2
num /= 2
num %= 2
```

常见写法：

- `=`：赋值。
- `+=`：加后赋值。
- `-=`：减后赋值。
- `*=`：乘后赋值。
- `/=`：除后赋值。
- `%=`：取余后赋值。

### 一元运算符

一元运算符只操作一个变量。

```javascript
let num = 10

++num // 先加 1，再使用
num++ // 先使用，再加 1

--num // 先减 1，再使用
num-- // 先使用，再减 1
```

前置和后置在单独使用时结果类似，但参与表达式计算时不同：

```javascript
let i = 1
console.log(++i + 1) // 3

let q = 1
console.log(q++ + 1) // 2
console.log(q) // 2
```

### 比较运算符

比较运算符的结果是布尔值。

```javascript
10 > 20 // false
10 < 20 // true
10 >= 10 // true
10 <= 10 // true
```

相等比较：

```javascript
10 == '10' // true，只比较值
10 === '10' // false，同时比较值和类型
10 !== '10' // true
```

建议日常优先使用 `===` 和 `!==`，避免隐式类型转换带来的误判。

### 逻辑运算符

```javascript
true && true // true
true || false // true
!true // false
```

- `&&`：逻辑与，两个条件都为真，结果才为真。
- `||`：逻辑或，只要一个条件为真，结果就为真。
- `!`：逻辑非，把结果取反。

### 运算符优先级

常见优先级顺序：

1. `()` 括号。
2. 一元运算符：`++`、`--`、`!`。
3. 算术运算符：先 `* / %`，后 `+ -`。
4. 比较运算符：`>`、`<`、`>=`、`<=`。
5. 相等运算符：`==`、`===`、`!=`、`!==`。
6. 逻辑运算符：先 `&&`，后 `||`。
7. 赋值运算符：`=`、`+=` 等。

不确定优先级时，优先使用括号让逻辑更清晰。

## 常见案例

### 判断闰年条件

```javascript
let year = +prompt('请输入年份')

let isLeapYear = year % 4 === 0 && year % 100 !== 0 || year % 400 === 0
alert(isLeapYear)
```

判断逻辑：

- 能被 `4` 整除，并且不能被 `100` 整除。
- 或者能被 `400` 整除。

### 自增运算面试题

```javascript
let a = 1

console.log(a++ + ++a + a) // 7
console.log(a) // 3
```

拆解：

- `a++` 先参与运算，值是 `1`，之后 `a` 变成 `2`。
- `++a` 先自增，`a` 变成 `3`，再参与运算。
- 最后的 `a` 是 `3`。
- 所以结果是 `1 + 3 + 3 = 7`。

### 根据用户输入判断条件

```javascript
let num = +prompt('请输入一个数字')
let result = num % 4 === 0 && num % 100 !== 0

alert(result)
```

这种写法适合练习“比较运算符 + 逻辑运算符”的组合。

## 易错点

- `==` 会发生隐式转换，`===` 不会，推荐使用 `===`。
- `num++` 和 `++num` 单独看类似，放进表达式里结果不同。
- `!a` 会先把 `a` 转成布尔值再取反。
- 多个逻辑条件混用时，建议加括号提升可读性。
- 字符串也可以比较，但比较的是字符编码顺序，不是自然语言顺序。

## 复习清单

- 能写出 `+=`、`-=`、`*=`、`/=`、`%=` 的含义。
- 能区分 `++num` 和 `num++`。
- 能说明 `==` 和 `===` 的区别。
- 能使用 `&&`、`||`、`!` 组合多个条件。
- 能用取余 `%` 判断奇偶、倍数和闰年。
- 能在复杂表达式中使用括号保证逻辑清晰。
